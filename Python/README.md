## 📚 Topics Covered

### Assignment 01: Core Foundations & Iterative Logic
- Iteration using `while` and `for` loops without built-in shortcuts.
- Number manipulation (reversing integers mathematically, counting digits, median calculations).
- Series summation (e.g., repeating digits $2 + 22 + 222 + \dots$).
- String operations (in-place duplicate removal preserving first occurrence).
- Factorial calculation and vowel/consonant character frequency analysis.

### Assignment 02: Algorithmic Problem Solving & Data Structures
- **Three Sum Problem**: Finding unique triplets that sum up to zero with two-pointer technique.
- **Array Rearrangement**: Organizing positive and negative integers in alternate sequences.
- **Pair Counting**: Efficient counting of pairs with target difference `k`.
- **Chocolate Distribution Problem**: Minimizing difference between maximum and minimum chocolates distributed among `m` students.
- **Roman Numerals**: Bidirectional conversion between Roman numerals and decimal integers.
- **Matrix Rotation**: In-place $90^\circ$ clockwise rotation of 2D matrices.

### Assignment 03: Native Data Structures Mastery
- **Lists (`task1_lists.py`)**: Slicing, indexing, list comprehensions, sorting, and manipulation.
- **Tuples (`task2_tuples.py`)**: Immutability properties, packing/unpacking, and multi-value returns.
- **Dictionaries (`task3_dictionary.py`)**: Hash maps, nested key lookups, frequency counting, and transformations.

### Assignment 04: Data Analysis with NumPy & Pandas
- **NumPy (`task1_operations_in_numpy.py`)**: Array creation, matrix reshaping, broadcasting, vector arithmetic, aggregation metrics, and boolean indexing.
- **Pandas (`task2_pandas.py`)**:
  - Loading real-world sports car price data (`1_Sport car price.csv`).
  - Handling missing data and string cleansing (e.g., removing commas from monetary values).
  - Descriptive statistics (mean, median, mode, standard deviation, interquartile range).
  - Grouping and aggregation by car manufacturer.
  - Multi-condition filtering and exporting cleaned datasets (`2_cleaned_sports_cars.csv`).

### Assignment 05: Object-Oriented Programming (OOP)
- Class and object architecture, encapsulation, inheritance, method overriding, and modular software design.
